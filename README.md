# Site de Formatura - Igor 🎓

Este repositório contém o sistema de confirmação de presença para a formatura do Igor.

## 🛠️ Tecnologias
- **HTML/CSS/JS:** Interface do convite.
- **Google Apps Script:** Ponte para salvar os dados.
- **Google Sheets:** Banco de dados das respostas.

## 📝 Como funciona:
O formulário envia um `POST` para o Google Apps Script, que por sua vez adiciona uma nova linha na aba "Respostas" da planilha vinculada.
